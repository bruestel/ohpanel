Commands that failed against some openHAB servers over https fixed, and no more redrawn pages when the panel
subscribes to the items it already has.
The display design is the one of 0.13.0: panels on 0.13 or 0.14 need only the firmware.

**Fixed**
- **Commands over https**: the panel keeps the TLS session of its command connection and resumes it, so a switch
  after a pause does not wait seconds for a full handshake (since 0.13.0). A server that does not take the resumed
  session failed every command after the first one, with `mbedtls_ssl_handshake returned ...` and
  `openHAB not reachable (HTTP 0)` in the log, while the states still came in. Such a command is now sent once more
  with a full handshake, and the session is made anew. The log says so: `no connection on the saved TLS session,
  once more with a full handshake`, and `the full handshake went through` when the second try worked. If you see
  these on every command, please tell us how your openHAB is reached (directly, or behind a proxy such as nginx).
- **Pages drawn again**: subscribing to the same items again on the same stream (a cover's metadata naming a moving
  item the panel already shows, a configuration saved unchanged) made openHAB send every state anew, which
  overran the display and drew the page again. The same set is no longer sent twice.

**Install**
- Panels on 0.13 or 0.14: Settings > Firmware > Check for updates installs the firmware; the display design stays.
- Panels on 0.12 or older: the same, then the display design it offers.
- An NSPanel EU by hand: `ohpanel-nspanel-eu-firmware-0.14.1.bin` from `ohpanel-nspanel-eu-0.14.1.zip` (display
  design `ohpanel-nspanel-eu-display-4e7603bf.tft`, unchanged).
- An NSPanel US by hand: the same from `ohpanel-nspanel-us-0.14.1.zip` (upright, display design
  `ohpanel-nspanel-us-display-67c9b1ac.tft`) or `ohpanel-nspanel-us-landscape-0.14.1.zip` (on its side, display
  design `ohpanel-nspanel-us-landscape-display-26f73ca8.tft`).
- A new panel, or coming from Tasmota or Sonoff's firmware: flash the factory image of its zip over the serial port,
  flash erased first ([docs/install.md](https://github.com/bruestel/ohpanel/blob/v0.14.1/docs/install.md)).
- Each zip holds that panel's factory image (serial, offset 0), the firmware for updates over WiFi and the display
  design, and the licences that go with the binaries.
