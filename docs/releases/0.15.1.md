A large cover no longer restarts the panel, and each release carries the files to read a crash report.
The display design is the one of 0.13.0: panels on 0.13, 0.14 or 0.15 need only the firmware.

**Fixed**
- **A large cover restarted the panel**: the panel downloads a cover into a buffer that grows as the picture comes.
  A cover over 256 KB needed it to grow to 512 KB in one piece; when the memory had no block that large, the
  firmware aborted (a panic in the task `cover`) instead of failing the download. Now the buffer takes the size the
  server announces at once, and when there is no room for it the download fails with "no memory" in the log and the
  icon stays, without a restart. The same for the panel's other downloads from openHAB.

**Changed**
- Each release has `elf-ohpanel-<version>.zip`: the firmware's `.elf` of each panel variant, to decode a core dump
  of a release build ([docs/crash-analysis.md](https://github.com/bruestel/ohpanel/blob/v0.15.1/docs/crash-analysis.md)).
  Not needed to install anything.

**Install**
- Panels on 0.13 or later: Settings > Firmware > Check for updates installs the firmware; the display design stays.
- Panels on 0.12 or older: the same, then the display design it offers.
- An NSPanel EU by hand: `ohpanel-nspanel-eu-firmware-0.15.1.bin` from `ohpanel-nspanel-eu-0.15.1.zip` (display
  design `ohpanel-nspanel-eu-display-4e7603bf.tft`, unchanged).
- An NSPanel US by hand: the same from `ohpanel-nspanel-us-0.15.1.zip` (upright, display design
  `ohpanel-nspanel-us-display-67c9b1ac.tft`) or `ohpanel-nspanel-us-landscape-0.15.1.zip` (on its side, display
  design `ohpanel-nspanel-us-landscape-display-26f73ca8.tft`).
- A new panel, or coming from Tasmota or Sonoff's firmware: flash the factory image of its zip over the serial port,
  flash erased first ([docs/install.md](https://github.com/bruestel/ohpanel/blob/v0.15.1/docs/install.md)).
- Each zip holds that panel's factory image (serial, offset 0), the firmware for updates over WiFi and the display
  design, and the licences that go with the binaries.
