The weather page shows the high and the low on one line, and the web interface loads itself anew after a firmware
update. With a new display design: update the firmware first, then the display design (Settings > Firmware > Check
for updates).

**Changed**
- **The weather page's high and low**: both in one line, the same size, an arrow up before the high and an arrow
  down before the low. With the condition in words (`condition`), the line sits at the top and the words under it;
  without them, the line sits in the middle beside the icon. Needs the new display design.

**Fixed**
- **The web interface after a firmware update** (GitHub #8, forum #174): the page open in the browser stayed the
  old one and saved the configuration by the old rules (a touch tone "none" came back as a click, for example).
  Now the page loads itself anew once the panel runs another firmware. With changes not yet saved it shows a
  note in the save bar instead: save, or copy the JSON (Advanced), then reload the page. An update started on
  the page goes on after the reload.
