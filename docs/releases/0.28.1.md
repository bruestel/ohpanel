Commands and states from the panel name the panel in openHAB. No new display design: the firmware alone.

**Changed**
- **The panel's name as the source in openHAB** (GitHub #12): what the panel sends to openHAB (commands, states)
  carries the device name as its source instead of a fixed `ohpanel`, so a rule can tell several panels apart. The
  event log shows, for example, `source: kitchen=>org.openhab.core.io.rest$admin`; a panel without a name of its own
  sends its default name (`ohpanel-a1b2c3`). A new name counts from the next start, as for the network name.
