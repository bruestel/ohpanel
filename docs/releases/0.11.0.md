OHpanel 0.11.0: a keypad page, home that can be left out, more page types in the swipe row, the logo
drawn in as the display starts. The same as the test build 0.11.0-rc1. It needs the new display design on every panel.

**New**
- **Keypad** (page type `keypad`): a code typed on the panel and sent with up to four buttons, for an alarm system's
  modes or a door's "Open". The code shows only as places filling, never as digits, and is not logged by the panel.
  Over it the state in words, icon and colour from its rules; buttons lit by the state, or shown only in some
  states (`show_when`); "Not accepted" when the state does not follow, or a reply item's text
  ([docs/panel-config.md](https://github.com/bruestel/ohpanel/blob/v0.11.0/docs/panel-config.md#keypad)).
- **The start page**: the swipe row's first page. The panel starts there and goes back to it (back, the close
  cross, the time without a touch); it has no close cross. Home is in the row only where the row names it, so a
  panel can do without home. In the web interface home is an entry of the swipe row like the others.
- **More page types in the swipe row**: lists (entities), the weather, QR codes and the info page, besides button
  pages. A list's or the weather's sheets come before the next page; swiping back lands on its last sheet.
- **Page dots for every sheet**: in the swipe row each sheet of each page is a dot, across the bottom of the screen.
  QR and info pages have them too.
- As the display starts it shows the logo, larger, drawn in on black, until the firmware takes over. After a
  restart that was not a power-on the display is switched off and on, so it starts the same way instead of showing
  its last page frozen.
- A release has a zip per panel: `ohpanel-nspanel-eu-0.11.0.zip` and `ohpanel-nspanel-us-0.11.0.zip`.

**Changed**
- A swipe row written by hand without `"home"`, or with another page first, now means exactly that: no home, or
  that page as the start page. Rows the web interface wrote always began with home and are not affected.

**Fixed**
- The web interface's preview: a station's own logo was cut off square; the title's place on the NSPanel US.

**Install**
- An NSPanel EU: Settings > Firmware with `ohpanel-nspanel-eu-firmware-0.11.0.bin` from
  `ohpanel-nspanel-eu-0.11.0.zip`, then write the display design `ohpanel-nspanel-eu-display-8072d6ec.tft`.
- An NSPanel US: the same from `ohpanel-nspanel-us-0.11.0.zip`, the display design
  `ohpanel-nspanel-us-display-fb4f8ee7.tft`; a new one: `ohpanel-nspanel-us-factory-0.11.0.bin` over the serial
  port, flash erased first ([docs/install.md](https://github.com/bruestel/ohpanel/blob/v0.11.0/docs/install.md)).
  The US version is still untried on a real panel.
- Coming from Tasmota or Sonoff's firmware: flash the factory image over the serial port, flash erased first.
- Each zip holds that panel's factory image (serial, offset 0), the firmware for updates over WiFi and the display
  design, and the licences that go with the binaries.
