A media page can show the time. The display design is the one of 0.17.0: panels on 0.17.0 or later need only the
firmware.

**New**
- **A clock on the media page** (`"clock": true`): the time in the title's row, before the close cross, in the title's
  size and the display's `time_format`. The title then stands a few pixels lower, level with the cross, and is cut off
  before the clock where the row is too short (the NSPanel US upright).
- **The media page's title** is the light grey of every other page's now, with or without a clock; the time as well.
- **In the web interface**: Edit in the preview of a media page, the switch *Show the clock at the top right*.
