A media page can show the time, an info line's text takes the whole line when its right field is empty, and the
panel's https can use a certificate of your own, from Let's Encrypt for example. With a new display design: update the
firmware first, then the design.

**New**
- **A clock on the media page** (`"clock": true`): the time in the title's row, before the close cross, in the title's
  size and the display's `time_format`. The title then stands a few pixels lower, level with the cross, and is cut off
  before the clock where the row is too short (the NSPanel US upright).
- **The media page's title** is the light grey of every other page's now, with or without a clock; the time as well.
- **An info line's main text on the whole line** while its right field is empty: 264 px instead of 182 on the NSPanel
  US upright, 212 instead of 130 on the others. Since 0.17.0 the right field's room for "11:11 AM" was kept free, with
  nothing in it too, and a text that fitted before ended in "...".
- **Your own server certificate**: Security, *Use your own server certificate* takes a certificate with its chain and
  its key and answers https with it as it is. `POST /api/v1/tls/server` does the same for a renewal script; the install
  guide has a deploy hook for acme.sh.
- **In the web interface**: Edit in the preview of a media page, the switch *Show the clock at the top right*.

**Fixed**
- **The own CA dialog** says that a certificate from Let's Encrypt is no CA, and refuses one with that reason instead
  of "too long".
- **The panel's server certificate stays over a restart**: it was issued anew at each start, for the moment the panel
  did not know its address yet, and again when it did. A new one comes when a name or an address is new.
