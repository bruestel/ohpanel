A shortcut now opens its page whenever it is shown, so one switch less in the web interface.
The display design is the one of 0.17.0: panels on 0.17.0 need only the firmware.

**Changed**
- **A shortcut opens its page whenever it is shown**, and only then: what shows on the screen can be tapped, what
  does not show cannot. `"show": "always"` opens always, `"when_on"` (the default with an item) while its item is on.
  - A shortcut shown always with an item that is off opens now; it did not before.
  - A shortcut hidden while its item is off no longer opens, even with `open_when_off`: tapped, its empty place
    does nothing. For that, set `"show": "always"`.
  - A shortcut with `"show": "when_on"` and no item never shows, so it no longer opens.
- **`open_when_off` is gone** from the web interface ("Opens it while the item is off too"). Configurations that have
  it stay valid; it does nothing now.
- **The web interface** shows "On when" only for a status icon or shortcut shown while its item is on: shown always,
  it changes nothing, now for a shortcut's link too.

**Install**
- Panels on 0.17.0: Settings > Firmware > Check for updates installs the firmware; the display design stays.
- Panels on 0.16 or older: the same, then the display design it offers.
- An NSPanel EU by hand: `ohpanel-nspanel-eu-firmware-0.17.1.bin` from `ohpanel-nspanel-eu-0.17.1.zip` (display
  design `ohpanel-nspanel-eu-display-d78edeec.tft`, unchanged).
- An NSPanel US by hand: the same from `ohpanel-nspanel-us-0.17.1.zip` (upright, display design
  `ohpanel-nspanel-us-display-926cd92d.tft`) or `ohpanel-nspanel-us-landscape-0.17.1.zip` (on its side, display
  design `ohpanel-nspanel-us-landscape-display-61bfd2ee.tft`).
- A new panel, or coming from Tasmota or Sonoff's firmware: flash the factory image of its zip over the serial port,
  flash erased first ([docs/install.md](https://github.com/bruestel/ohpanel/blob/v0.17.1/docs/install.md)).
- Each zip holds that panel's factory image (serial, offset 0), the firmware for updates over WiFi and the display
  design, and the licences that go with the binaries. `elf-ohpanel-0.17.1.zip`: the `.elf` files to decode a core
  dump ([docs/crash-analysis.md](https://github.com/bruestel/ohpanel/blob/v0.17.1/docs/crash-analysis.md)).
