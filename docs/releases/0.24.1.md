Long weekday and month names on the home screen, from the web interface. Only the firmware: the display design is the
one of 0.24.0.

**New**
- **Dates with long names in the web interface**: the date format list offers `%A, %e %B` ("Monday, 5 October") and
  its kin, and "Own format…" takes any format typed in (`%A`, `%B`, `%-d.%-m.` ...) -- the panel took them before,
  only from the JSON.
- **A long date drawn smaller**: a date too wide for the home screen's field shows in a smaller font (22 or 18 px
  instead of 26) before it is shortened with "…". The web interface's preview draws it the same way.
