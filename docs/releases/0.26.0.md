A page for a picture -- a camera's snapshot, a doorbell's --, covers from Image items, help in the web interface,
and a certificate Apple's devices take. Only the firmware: the display design is the one of 0.25.0
(Settings > Firmware > Check for updates).

**New**
- **The image page** (`"type": "image"`): one picture under the title, as large as fits -- a camera's snapshot
  (`"url"`, fetched again every 10 s or as `"refresh"` says), or an Image item's (a doorbell's snapshot), or an
  address an item holds. Drawn by the panel, no new display design needed. In the swipe row too. See *image* in
  the configuration docs.
- **Help in the web interface**: a *Help* page in the menu with the links to the documentation, the community
  thread and GitHub issues, and what is new in the running version; every card and the page editor have a *Docs*
  link to their part of the documentation, as it is for the firmware running (thanks ubeaut, forum #138).
- **Status page: the relays**, on or off as they are switched.
- **Status page: Security** -- whether this page came encrypted, the https server, the server certificate (until
  when, for which names; orange 30 days before it runs out), the CA and whether a password protects the panel.

**Changed**
- **The panel's https certificate is valid for 820 days** and is issued anew 30 days before it runs out, by the
  panel's CA (or yours): iPhones, iPads and Macs take no server certificate valid longer than 825 days, not even
  from a CA one trusts. A panel issues its new one right after the update; a device that trusts the CA notices
  nothing.
- **The clock without NTP**: where no time server answers (a network without internet), the panel takes the time
  from openHAB's answers -- the home screen's clock and the certificate's dates. NTP, once it answers, wins.
- **Image items as the media page's cover** (`art`): openHAB's stream gives a picture only as its size ("raw type
  (image/jpeg): 219955 bytes"), so the cover stayed empty. The panel now fetches the picture from openHAB when the
  page shows it, and again when it changes (Spotify, Chromecast, Squeezebox, Kodi), up to 400 KB.
- **The openHAB stream is read item by item**: the list of all states after connecting is no longer held in one
  piece, and a state too large to keep (over 64 KB) is left out, with a line in the log, instead of breaking the
  connection.
- **The BOM weather rule** in the configuration docs fetches the forecast itself, every two hours, by your place's
  geohash: no item with BOM's data needed any more (thanks ubeaut, forum #142). It also reads each day in the
  place's time zone: the rule before showed every day a day early (forum #147).

**Fixed**
- **The cover group's form** says where the table's *Moving item* and *Command item* come from: each member's
  `cover` metadata, `moving` and `command_item` (forum #146).
- **Password protection switched on** (or a new password saved while it is on): the page ran into nothing, every
  request refused in the background without a login dialog. It loads anew now, the browser asks for the password;
  any later refused request does the same (not over unsaved panel changes).
- **A name added for the certificate** (Security, *Names the certificate covers*) now covers the names right under
  it too, as the CA allows: `kitchen.panel.home.example` with `panel.home.example` added. Added names are limited
  to what fits the certificate (refused with a message); one that could not be stored is used all the same until
  the next start -- before, the panel had no https then.
- **Thermostat modes in the web interface**: a mode's name typed before what it sends was lost, the mode saved
  without a name (`"label": ""`). Now kept whatever is typed first (thanks gd35, forum #143).
- **The log full of "queue full, dropping a display job"** while a cover was drawn: the display's flow-control
  answers went into the display's queue too. Nothing was lost, but the log was flooded.
- **"display reports status 0x1A"** opening a page from home with animated icons: a last frame went to the page
  just left.
