A thermostat page can now show another unit than degrees: a dehumidifier in %, say. The display design is the one of
0.17.0: panels on 0.17.0 or later need only the firmware.

**New**
- **A thermostat's unit** (`"unit": "%"`): shown after the value now and the target instead of the degree sign and the
  item's unit. Only what is shown changes, nothing is converted and a command keeps the item's unit. A value too wide
  for the large text with its unit is written smaller rather than cut. Without it everything stays as it was.
- **In the web interface**: Edit in the preview of a thermostat page, Unit.

```json
{"id": "humidity", "type": "thermostat", "title": "Humidity", "item": "Dehumidifier_Target",
 "current": {"item": "Dehumidifier_Humidity"}, "unit": "%", "min": 30, "max": 80, "step": 1}
```

**Install**
- Panels on 0.17.0 or later: Settings > Firmware > Check for updates installs the firmware; the display design stays.
- Panels on 0.16 or older: the same, then the display design it offers.
- An NSPanel EU by hand: `ohpanel-nspanel-eu-firmware-0.19.0.bin` from `ohpanel-nspanel-eu-0.19.0.zip` (display
  design `ohpanel-nspanel-eu-display-d78edeec.tft`, unchanged).
- An NSPanel US by hand: the same from `ohpanel-nspanel-us-0.19.0.zip` (upright, display design
  `ohpanel-nspanel-us-display-926cd92d.tft`) or `ohpanel-nspanel-us-landscape-0.19.0.zip` (on its side, display
  design `ohpanel-nspanel-us-landscape-display-61bfd2ee.tft`).
- A new panel, or coming from Tasmota or Sonoff's firmware: flash the factory image of its zip over the serial port,
  flash erased first ([docs/install.md](https://github.com/bruestel/ohpanel/blob/v0.19.0/docs/install.md)).
- Each zip holds that panel's factory image (serial, offset 0), the firmware for updates over WiFi and the display
  design, and the licences that go with the binaries. `elf-ohpanel-0.19.0.zip`: the `.elf` files to decode a core
  dump ([docs/crash-analysis.md](https://github.com/bruestel/ohpanel/blob/v0.19.0/docs/crash-analysis.md)).
