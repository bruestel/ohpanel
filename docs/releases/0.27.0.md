What is new in 0.27.0, so far: fixes. Only the firmware: the display design is the one of 0.25.0 (Settings > Firmware > Check for updates).

**Fixed**
- **Labels with a sitemap format**: an item made in openHAB's UI with a label the way of `.items` files,
  `Front door [%s]`, keeps the `[%s]` in its label word for word, and the panel showed it -- on an entity page's
  rows, in the cover group's table, in the item search. The panel now leaves a format at a label's end out, as
  openHAB's sitemaps do; the row shows the state itself anyway. A label you give in the panel's configuration is
  shown as you wrote it. (Thanks obones, issue #7; the cleaner way in openHAB is the item's *State Description*
  metadata, as riegelbrau wrote there.)
