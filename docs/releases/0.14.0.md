OHpanel 0.14.0: openHAB opens a page, a keypad that stays, a page's id in the web interface.
The display design is the one of 0.13.0: panels on 0.13 need only the firmware.

**New**
- **A page opened by openHAB**: `display.open_page` names a String item; a page id set on it opens that page
  from wherever the panel is, and wakes the screen. Once the page is open the panel sets the item to NULL, so a
  rule sees it done and can ask for the same page again. An id the panel does not know is left on the item
  ([docs/panel-config.md](https://github.com/bruestel/ohpanel/blob/v0.14.0/docs/panel-config.md)). In the web
  interface: Display, *Open a page*.
- **A keypad that stays**: `"stay": true` on a keypad page keeps it open, for an alarm panel by the door: no going
  back to the start page after a while without a touch, and a screen that went off wakes on it. The close cross
  still leaves it. A switch in the keypad's editor.
- **A page's id in the web interface**: each page's editor shows its id and changes it; what points to the page
  (the swipe row, shortcuts, tiles, the weather icon) follows. The id is what `open_page` and the configuration
  name a page by.
- **Notifications in the preview**: the web interface's preview draws a notification card as the panel does, and
  the display settings have one to try before a rule sends it. The README shows three.

**Install**
- Panels on 0.13: Settings > Firmware > Check for updates installs the firmware; the display design stays.
- Panels on 0.12 or older: the same, then the display design it offers.
- An NSPanel EU by hand: `ohpanel-nspanel-eu-firmware-0.14.0.bin` from `ohpanel-nspanel-eu-0.14.0.zip` (display
  design `ohpanel-nspanel-eu-display-4e7603bf.tft`, unchanged).
- An NSPanel US by hand: the same from `ohpanel-nspanel-us-0.14.0.zip` (upright, display design
  `ohpanel-nspanel-us-display-67c9b1ac.tft`) or `ohpanel-nspanel-us-landscape-0.14.0.zip` (on its side, display
  design `ohpanel-nspanel-us-landscape-display-26f73ca8.tft`).
- A new panel, or coming from Tasmota or Sonoff's firmware: flash the factory image of its zip over the serial port,
  flash erased first ([docs/install.md](https://github.com/bruestel/ohpanel/blob/v0.14.0/docs/install.md)).
- Each zip holds that panel's factory image (serial, offset 0), the firmware for updates over WiFi and the display
  design, and the licences that go with the binaries.
