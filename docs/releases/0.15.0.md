The page on screen to openHAB, and a favourite's logo in the player.
The display design is the one of 0.13.0: panels on 0.13 or 0.14 need only the firmware.

**New**
- **The page on screen to openHAB**: `display.current_page` names a String item; the id of each page that opens
  (`home` for home) is sent to it as a command, by a touch, a swipe, `open_page` or the way back to the start page.
  A rule triggered by *received command* can act on it, such as turning on an amplifier when the media page opens
  ([docs/panel-config.md](https://github.com/bruestel/ohpanel/blob/v0.15.0/docs/panel-config.md)). The same page
  drawn again (a configuration saved) is not sent; while the screen is off nothing is, and woken the page is sent
  again. In the web interface: Display, *The page on screen*.

  ```
  rule "Amplifier on with the panel's media page"
  when
      Item Panel_CurrentPage received command
  then
      if (receivedCommand.toString == "speaker") Amplifier_Power.sendCommand(ON)
  end
  ```
- **A favourite's logo in the player**: while a station from the favourites plays (the player shows its name), its
  logo shows in the cover's box instead of the music icon, twice the size of its tile. A cover the speaker sends
  wins over it; a station without a logo shows the icon as before.

**Since 0.14.0** (in 0.14.1 to 0.14.3, for panels coming from 0.14.0 or older)
- Commands over https resume their TLS session with openHAB behind a public certificate (a full handshake each
  time before, or failing).
- An album cover no longer takes about 80 KB of the internal RAM while it is made.
- The log holds 256 KB (days instead of an hour), all of it in Diagnostics and its *Download*.

**Install**
- Panels on 0.13 or 0.14: Settings > Firmware > Check for updates installs the firmware; the display design stays.
- Panels on 0.12 or older: the same, then the display design it offers.
- An NSPanel EU by hand: `ohpanel-nspanel-eu-firmware-0.15.0.bin` from `ohpanel-nspanel-eu-0.15.0.zip` (display
  design `ohpanel-nspanel-eu-display-4e7603bf.tft`, unchanged).
- An NSPanel US by hand: the same from `ohpanel-nspanel-us-0.15.0.zip` (upright, display design
  `ohpanel-nspanel-us-display-67c9b1ac.tft`) or `ohpanel-nspanel-us-landscape-0.15.0.zip` (on its side, display
  design `ohpanel-nspanel-us-landscape-display-26f73ca8.tft`).
- A new panel, or coming from Tasmota or Sonoff's firmware: flash the factory image of its zip over the serial port,
  flash erased first ([docs/install.md](https://github.com/bruestel/ohpanel/blob/v0.15.0/docs/install.md)).
- Each zip holds that panel's factory image (serial, offset 0), the firmware for updates over WiFi and the display
  design, and the licences that go with the binaries.
