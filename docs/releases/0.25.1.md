Changes made on the panel are no longer lost when the web interface saves. Only the firmware: the display design is the
one of 0.25.0.

**Fixed**
- **A setting changed on the panel survives a save in the browser** (GitHub #6): the panel's settings page keeps the
  brightness, the dimming and the volumes in the configuration. A web page opened before then asked whether to
  overwrite them, and saving replaced them (the dimming back at 60 seconds). Now it takes the newest configuration,
  keeps what was changed there and puts its own changes on top; it asks only when both changed the same value, and
  names it. The same for two browsers or tabs editing at once.
