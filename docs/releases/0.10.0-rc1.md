A test build: OHpanel for the **NSPanel US** -- the tall one, its screen upright -- next to the EU. Not yet tried on a
real US panel: if you have one, please tell us how it works (in an issue), what looks right and what does not.

**New**
- The NSPanel US has a firmware and a display design of its own, laid out upright (320 x 480, all of it visible): on
  home the weather and the clock on top, the values, shortcuts and info lines standing on the relays, whose labels
  sit over the two buttons; button pages with 2 x 4 wide tiles (eight a sheet, as on the EU); every other page
  rearranged upright. The configuration is the same for both: one made on an EU panel works on a US panel unchanged.
- Each panel takes only its own firmware: an NSPanel EU refuses the US firmware and the other way round. To try one
  variant's design on the other panel (the hardware is the same), the API takes it with `?any_variant=1`
  ([docs/flashing.md](https://github.com/bruestel/ohpanel/blob/main/docs/flashing.md#updates)).
- The status page names the panel: NSPanel EU or NSPanel US.
- The browser flasher will ask which panel it is (from the release after this test build on; it keeps the latest
  release).

**Changed**
- The display design's version is now worked out from the design itself, not from the files it is made from: a
  change to how the design is built that leaves it as it was no longer asks for a new display firmware. Once, with
  this release, the EU's version changes all the same (`bc629e1e` -> `4508cd3f`) with the design unchanged: write it
  once more.

**Install**
- Already running OHpanel on an NSPanel EU: Settings > Firmware with `ohpanel-nspanel-eu-firmware-0.10.0-rc1.bin`
  from `ohpanel-0.10.0-rc1.zip`, then write the display design `ohpanel-nspanel-eu-display-4508cd3f.tft` (the same
  design, a new version).
- An NSPanel US: flash `ohpanel-nspanel-us-factory-0.10.0-rc1.bin` over the serial port, flash erased first
  ([docs/install.md](https://github.com/bruestel/ohpanel/blob/main/docs/install.md); the browser flasher has only
  the latest release, without the US firmware yet); then write `ohpanel-nspanel-us-display-fc4305ba.tft`.
- Coming from Tasmota or Sonoff's firmware: flash the factory image over the serial port, flash erased first. An
  update from Tasmota over WiFi keeps Tasmota's partition table, in which OHpanel cannot store its configuration.
- `ohpanel-0.10.0-rc1.zip` holds, for each panel, the factory image (serial, offset 0), the firmware for updates
  over WiFi and the display design, and the licences that go with the binaries.
