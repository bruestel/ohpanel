A renewed server certificate can go to the panel without its private key. Only the firmware: the display design is the
one of 0.21.0.

**New**
- **A renewal without the key**: `POST /api/v1/tls/server` takes `cert` alone and keeps the key on the panel; a
  certificate made with a new key is refused, and the old one stays in use. The first upload still needs the key. The
  install guide's example and its deploy hook for acme.sh send the certificate only.
- **In the web interface**: *Replace your server certificate* works without the key.
- **In the install guide**: how to send a certificate that has run out with a pinned key, instead of `-k` or http,
  which give away the login.
