PNG covers, such as the station logos Sonos sends for radio, and notifications that tell openHAB when they were read.
The display design is the one of 0.13.0: panels on 0.13 or later need only the firmware.

**New**
- **PNG covers**: the media page shows a PNG cover as well as a JPEG. Sonos sends a radio station's logo as a PNG
  (`getaa`, 600 x 600), which showed only the music icon before. The PNG is decoded row by row, never whole in
  memory (a 600 x 600 logo takes a few KB): grey, RGB or a palette, with transparency, which lies on the cover box's
  grey. Interlaced PNGs and progressive JPEGs are not shown; the log says so (`cover: ...`).
- **A notification read**: a touch that closes a notification's card sets its item to NULL. A rule sees it read and
  can send the next one, so several sources (a fridge door, a back door) can show one after the other; every panel
  showing it takes it away; and the same text can be sent again without setting the item to NULL first. An example
  rule: [docs/panel-config.md](https://github.com/bruestel/ohpanel/blob/v0.16.0/docs/panel-config.md). A rule that
  read the item's text after the card was closed now finds NULL there.

**Fixed**
- The touch that wakes the screen no longer closes a notification shown on it: the card comes back with the page,
  and the next touch closes it.

**Install**
- Panels on 0.13 or later: Settings > Firmware > Check for updates installs the firmware; the display design stays.
- Panels on 0.12 or older: the same, then the display design it offers.
- An NSPanel EU by hand: `ohpanel-nspanel-eu-firmware-0.16.0.bin` from `ohpanel-nspanel-eu-0.16.0.zip` (display
  design `ohpanel-nspanel-eu-display-4e7603bf.tft`, unchanged).
- An NSPanel US by hand: the same from `ohpanel-nspanel-us-0.16.0.zip` (upright, display design
  `ohpanel-nspanel-us-display-67c9b1ac.tft`) or `ohpanel-nspanel-us-landscape-0.16.0.zip` (on its side, display
  design `ohpanel-nspanel-us-landscape-display-26f73ca8.tft`).
- A new panel, or coming from Tasmota or Sonoff's firmware: flash the factory image of its zip over the serial port,
  flash erased first ([docs/install.md](https://github.com/bruestel/ohpanel/blob/v0.16.0/docs/install.md)).
- Each zip holds that panel's factory image (serial, offset 0), the firmware for updates over WiFi and the display
  design, and the licences that go with the binaries. `elf-ohpanel-0.16.0.zip`: the `.elf` files to decode a core
  dump ([docs/crash-analysis.md](https://github.com/bruestel/ohpanel/blob/v0.16.0/docs/crash-analysis.md)).
