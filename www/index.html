Setup hotspot

Opens when the panel cannot reach its network, or when the right button on the panel is held for 15 seconds (the panel then leaves its network for 10 minutes; a short press on either button closes it again, switching the relay as always). It is an open network named like the panel; the display shows its name and a QR code to join, the setup page is at http://192.168.4.1. The password protection below, when on, guards it there too.

Preview

Layout, fonts and pictures come from the display design; values are live from openHAB where the panel already receives them.

Use it like the panel: swipe (or the arrows, or the arrow keys), tap buttons to open pages, the cross goes back.

Pages

Display

How the panel's screen looks (time and date formats: the clock in the preview's edit mode).

Screen

How bright it is in use and idle, and off at night: then a touch only wakes it. Each number can be kept in step with an openHAB item (a Dimmer or Number): a change there comes here, a change here goes there.

Notifications

A String item: each new state shows as a card over the page, until it is touched. level|title|text, the level info (blue), warning (yellow) or alert (red); empty or NULL takes it away. The same text twice shows once: set the item to NULL before.

Advanced

the configuration as a file and as JSON

The whole configuration of the display: the preview, the pages and the display settings edit it, Save (on top) stores it on the panel. The format is described in docs/panel-config.md; saving checks it and lists what is wrong.

Time

      
The timezone sets how the panel and this page show the time. The clock is set from a
        time server when the panel connects and every hour after. Without one entered here, the network's
        is asked first (the one DHCP hands out, if the router offers one), then pool.ntp.org; one entered
        here takes its place, with pool.ntp.org still behind it.

      

        

          
          
        

        

      

    

  

  

    

      
Temperature sensor

      
The panel warms itself, so its sensor reads high: compare with a thermometer in the room
        and correct it with the offset. With an openHAB item (a Number or Number:Temperature item, no binding
        needed), the panel reports the corrected value as the item's state: checked every minute, sent when it
        changed, and at least every ten minutes.

    When do I need more names?
        
    Do you reach the panel under another name as well, for example one you gave it in your router or
          your own DNS server (panel.myhome.example)? Add it here. The certificate then covers that name and every name
          below it (such as kitchen.panel.myhome.example).
    
        
    Reaching it by a global IPv6 address? The CA vouches only for private addresses; add your network's
          prefix (such as 2001:db8:1:2::/64) and the certificate covers the panel's address in it. Only worth it if your
          provider keeps the prefix. A unique local address (fd…), which many routers hand out besides, is covered
          without that.
    
        
    With the panel's own CA, saving a change makes a new CA certificate: download it again and replace
          the old one on every device.

    Backup
    
      
    Everything the panel is set up with, in one file: device name, WiFi, password protection,
        openHAB, time and sensor; ticked, also the panel configuration and the passwords.
    
      
      
      
    A file with passwords opens your WiFi and openHAB: keep it safe.
    
      
    
        
      
    
      
    Restore
    
      
    What the backup holds replaces the settings; passwords and a panel configuration it does not
        hold stay as they are. The panel reboots afterwards.

      Use your own CA
      
  
      The panel issues its server certificate with your CA. Handy when your devices trust it already, or to
    share one CA between all your panels: upload the same one to each.
      
  
      No CA yet? Make one on your computer: tools/make_ca.sh "My home CA"
      
  
      
    
    
  
      
  
      
    
    
  
      
  
      
    
    
  
      
  
      Devices that trust the current CA need the new one. The key stays on the panel: it can not be downloaded
    again, not in a backup either.
